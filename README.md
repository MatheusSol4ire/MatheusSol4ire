🩺 casa-idosos — controle de medicação

Aplicação web em Flask para uma instituição de acolhimento de idosos, feita como projeto de extensão. É o projeto que junta as duas metades da minha história: eu conheço a rotina que ele atende porque já trabalhei nela.

Cadastro de residentes com quarto, data de nascimento e alergias
Medicamentos vinculados a cada residente, com dosagem e múltiplos horários
Login de funcionários com senha em hash bcrypt e rotas restritas
Baixa lógica em vez de exclusão — o registro sai da lista do dia, mas continua no histórico e pode ser reativado. Em saúde, apagar dado não é opção.
